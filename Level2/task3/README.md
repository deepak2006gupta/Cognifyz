# File Encryption and Decryption

This task contains a Java program that encrypts and decrypts file content.

Files
- FileEncryptionDecryption.java
- input.txt
- encrypted_input.txt
- decrypted_encrypted_input.txt

How to run
1. Open a terminal in this folder.
2. Compile: javac FileEncryptionDecryption.java
3. Run: java FileEncryptionDecryption
