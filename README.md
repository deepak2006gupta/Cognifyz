This workspace contains a collection of Java mini applications organized by level. The repository includes console programs, small interactive exercises, file-processing utilities, chat applications, an expense tracker, and a currency converter.

## General Running Pattern

Most folders contain a single Java application that can be compiled and run from that folder.

Typical steps:
1. Open a terminal in the task folder.
2. Compile the Java source files with javac.
3. Run the main class with java.

For multi-class applications such as the chat programs and the expense tracker, compile all Java files in the folder before running the main class.
